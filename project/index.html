Projects

The following projects are developed and maintained to support research in computational chemistry. Video tutorials of these projects are also available on YouTube.



Eigen Spaces - Interactive Notebook for Learning Fundamental Python in Scientific Computing

Eigen Spaces is an open learning resource for students and researchers who interested in applying Python to solve physics or chemistry problems, to manage and transform data, and to produce publication-quality figures. The goal of this project is to introduce the link between the Python language and the key concepts in data science, basics quantum mechanics and thermodynamics.

Figure. Examples of data visualizations using Python on various topics

In this projects I write the theoritical concepts, prerequisite topics, function arguments, clear Python scripts, data file,and references for each topics. With this foundations, readers can learn the theory behind the code, practice directly through the Google Colab link at the top of page (no require local installation), and explore the further material through the refences. If this projects succeeds, it may be possible to continue to the advanced topics, such as machine learning and deeplearning.

Project repository can be found here.


Data Processing - Practical Guide to Interpreting Materials Characterization Results

Data processing is a digital textbook that focuses on the used computational and analytical steps for processing and interpreting data from several characteriation tools: chemical, structural mineralogical, morphological, optical, and surface pore size.The goal of this project is to provide a concise documentation of both the theoritical and practical applications of the techniques reported in past and recent publications.

Figure. Data processing pipeline from raw data to interpretation

In this project I provide the prerequisite question (what we need to understand before analyse), technique fundamentals, wokflows for process ing data and case studies. Readers can follow the pipelines and work with the data, and learn how to analysis and interpret the results.

Project repository can be found here.


DFT Toolkit - Algorithm Experimentations for DFT Calculations

Predicting chemical properties using a first-priciple method at the atomic scale is a theoritical and computational challenge. That is why I learn and pratice how to simulate crystalline and amorphous structure use open-source Python packages, and verify the results from reported data in recent and past publications.

Figure. Comparison between the work and reference data on the electronic energy levels of 4-amino-2,2'-bypyridine (J. Mater. Chem. C, 2016,4, 2931-2935)

This project helps me build a deep understanding of practical aspect of DFT implementations such as density functional approximations, geometry optimization, vibrational and molecular properties, and transition energies. With this foundations I have skills to construct the workflows, including the set functionals and basis set.

Project repository can be found here
